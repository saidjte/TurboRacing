# TurboRacing

لعبة سباق سيارات 2D بمنظور شخص ثالث لأندرويد — مبنية بـ Unity وتُبنى تلقائياً إلى APK عبر GitHub Actions.

## كيف يعمل البناء التلقائي؟
1. عند كل `push` إلى `main` يعمل workflow ‏`.github/workflows/build-android.yml`
2. يستخدم `game-ci/unity-builder@v4` بإصدار Unity **6000.0.84f1** (منصّة Android)
3. ينفذ `BuildCommand.PerformBuild` الذي:
   - يضبط إعدادات اللاعب لأندرويد (أفقي، ARM64+ARMv7، API 24+)
   - ينشئ المشهد برمجياً (كاميرا + GameBootstrap)
   - يبني `build/Android/TurboRacing_v{الإصدار}.apk` (الاسم من GameVersion)
4. يُرفع الـ APK كـ **Artifact** باسم `TurboRacing-APK`

## البنية
```
Assets/
├── Scripts/
│   ├── CarController.cs      فيزياء السيارة (Rigidbody2D بلا جاذبية) + أزرار لمسية ذاتية الربط
│   ├── TrackBuilder.cs       حلبة Tilemap كاملة بالكود: عشب/طريق/كيرب/جدران + خط بداية
│   ├── SurfaceChecker.cs     عقاب العشب: خفض السرعة والتماسك خارج المسار
│   ├── CameraFollow.cs       كاميرا تتبع سلسة
│   ├── SimpleBackground.cs   (المرحلة 1) أرضية شبكية - استُبدلت بالحلبة
│   └── GameBootstrap.cs      يبني محتوى المشهد بالكود عند التشغيل
├── Editor/
│   └── BuildCommand.cs       أمر البناء المخصص لبيئة CI
└── Scenes/Game.unity         مشهد بسيط (كاميرا + GameBootstrap)
```

## الحلبة (المرحلة 2)
- حلبة مستطيلة مغلقة 46×28 بلاطة (بلاطة = 2×2 وحدة) مع جزيرة عشبية داخلية
- مشدّدان (شكانات) يضيّقان الطريق أعلى اليسار وأسفل الوسط
- كيرب أحمر/أبيض تلقائي على حواف الطريق + خط بداية مقلّم
- جدران تحذير صفراء/سوداء حول الحلبة (تصادم CompositeCollider2D)
- الخروج للعشب: السرعة تنخفض إلى 45% والتماسك إلى 60% والسيارة تتعكر حتى العودة للمسار
- السباق عكس عقارب الساعة — الانطلاق من خط البداية مباشرة

## نظام اللفات (المرحلة 3)
- السباق = 3 لفات: 3 نقاط تفتيش إلزامية (يمين، أعلى، يسار) ثم خط النهاية = لفة صحيحة
- نطاق كل بوابة مقيّد بعرض الطريق: قطع الطريق عبر العشب لا يحتسب
- المؤقت يبدأ فعلياً عند أول عبور لخط النهاية باتجاه السباق
- HUD: عدد اللفة من الإجمالي + زمن اللفة الحالية + أفضل لفة + آخر لفة + شارة الإصدار
- أفضل زمن وإجمالي اللفات محفوظان في PlayerPrefs (يبقيان بين الجلسات)

## الواجهات الكاملة (المرحلة 4)
- **آلة حالات مركزية** `RaceFlow`: القائمة ← عد تنازلي ← سباق ← (وقفة) ← نتائج
- **القائمة الرئيسية**: العنوان + أفضل لفة وإجمالي اللفات المحفوظين + START RACE + HOW TO PLAY (شرح كامل) + QUIT
- **عد تنازلي** 3-2-1-GO والسيارة مجمّدة فيزيائياً حتى الانطلاق
- **زر إيقاف مؤقت** II في الـ HUD (أو ESC/زر الرجوع): استئناف / إعادة السباق / القائمة — الزمن والفيزياء يتجمدان كلياً
- **شاشة النتائج** بعد 3 لفات: أزمنة اللفات كلها (الأفضل بلون مميز) + الزمن الإجمالي + تنبيه NEW RECORD! + إعادة/قائمة
- **كاميرا القائمة**: تأطير الحلبة كاملة في القائمة الرئيسية ثم انتقال فوري لكاميرا السباق

## الكاميرا (v0.5.0)

## التحكم (v0.6.0)
- **تخطيط قياسي لألعاب السباق بالتسارع التلقائي**: زرا التوجيه `<` و `>` **مجمّعان معاً أسفل اليسار** + زر الفرامل `BRK` **الكبير أسفل اليمين** — إبهام يوجّه وإبهام يفرمل، وبدون أي زر في منتصف الشاشة حيث تظهر السيارة
- **زر فرامل أكبر** (340 وحدة كانفاس مقابل 300 للتوجيه) لسهولة الوصول إليه، والكل بمسافة مريحة من حواف الجهاز (لا زر ملاصق للزاوية)
- **حصانة ضد الالتصاق**: تحرير الزر تلقائياً عند انزلاق الإصبع خارجه (PointerDown + PointerUp + PointerExit) — لن تبقى السيارة تلف وحدها بعد الآن
- **تغذية بصرية فورية**: زر التوجيه يتوهج عنبرياً وزر الفرامل يتوهج أحمر أثناء الضغط
- **دعم لمس متعدد كامل**: توجيه وفرمل في نفس اللحظة بإصبعين مختلفين
- **تصفير ذكي للمدخلات** عند بدء/إعادة السباق أو العودة للقائمة (لا فرامل عالقة من جلسة سابقة)
- الفرامل توقف السيارة ثم ترجعها للخلف ببطء عند الاستمرار (أسلوب الموبايل)

## الصوت والمؤثرات (v0.7.0 — المرحلة 5)
- **صوت إجرائي بالكود 100%**: مولّد `AudioSynth` يبني كل المقاطع رياضياً عند الإقلاع (موجات جيبية ونشّارة وضجيج مُرشَّح مع أغلفة هجوم/تلاشٍ) — لا ملفات صوتية خارجية إطلاقاً، والحلقات المستمرة مضمونة السلاسة (كل الترددات مضاعفات 1/المدة)
- **صوت المحرك**: حلقة دائمة بثلاث حالات — خمول أثناء العد التنازلي، قيادة يرتفع طبقها من 0.85x إلى 2.1x مع السرعة، صمت في القوائم/الإيقاف/النتائج (الصوت لا يتأثر بـ Time.timeScale لذا يُسكَت صراحة)
- **مؤثرات القيادة**: صرير فرامل أثناء الفرملة الفعلية بسرعة + حفيف عشب عند الخروج عن الطريق (مع خفض طفيف لطبق المحرك على العشب)
- **مؤثرات السباق**: نقرة عند كل ثانية من العد + نغمة GO الأعلى + رنة صاعدة لكل لفة مكتملة + رنة رقم قياسي جديد (أربع نغمات صاعدة) بدل فانفار النهاية العادي
- **مؤثرات الاصطدام**: ارتطام (ضجيج مُرشَّح + دقة عميقة) تتدرج قوته مع شدة الاصطدام + اهتزاز كاميرا يتلاشى أُسّياً
- **مؤثرات بصرية**: آثار إطارات متلاشية (مخزون دائري 160 علامة بلا تخصيص ذاكرة) عند الانعطاف الحاد بسرعة أو الفرملة القوية + نقرة موحدة لكل أزرار الواجهة
- ضمانات: AudioListener يُضاف تلقائياً للكاميرا إن غاب، وكل الربط null-safe فلا تعطّل المرحلة أي شيء إن غاب مكوّن

## إصلاح دوران السيارة الذاتي والتحكم (v0.6.8)
- **السبب الجذري لدوران السيارة من تلقاء نفسها**: `angularDamping = 0` مع توجيه عبر `MoveRotation` — دالة التوجيه تخرج مبكراً عندما لا يضغط اللاعب، فلا شيء يمس السرعة الزاوية التي ضخّها تصادم الجدار، ومع إخماد الدوران = صفر تبقى السيارة تدور إلى الأبد وكاميرا المطاردة تدور معها
- **الإصلاح الجذري**: التوجيه أصبح يضبط `rb.angularVelocity` صريحاً كل خطوة فيزيائية — بدون مدخل توجيه تكون السرعة الزاوية صفراً (أي دوران من تصادم يموت فوراً)، ومع التوجيه يطابق الدوران مدخل اللاعب حصراً
- **تحصين المدخلات (تتبع الأصابع)**: لكل زر مجموعة معرفات المؤشرات الضاغطة عليه؛ الانزلاق من زر توجيه إلى الآخر يفعّل الزر الثاني فوراً (PointerEnter)، والضغط بجانب الزر ثم الانزلاق عليه يعمل أيضاً، وكل إطار تُمسح المعرفات التي انتهى لمسها فلا يبقى أي زر عالقاً مهما كانت طريقة رفع الإصبع
- **مادة الهيكل**: احتكاك = 0 مع ارتداد خفيف 0.15 — ملامسة الجدار تصبح انزلاقاً ناعماً بدل الالتصاق والتباطؤ المفاجئ
- **ثبات المستقيمات**: التوجيه يخف 25% تدريجياً قرب السرعة القصوى (قابل للضبط عبر highSpeedTurnFactor)
- إضافة: تصفير السرعة الزاوية عند إعادة السباق حتى لا تستأنف السيارة دوراناً قديماً

## إصلاح نصوص الأزرار (v0.6.7)
- **السبب الجذري المكتشف من لقطات المستخدم**: دالة `UiKit.MakeButton` كانت تستقبل معامل `label` وتتجاهله — لم تكن تسنده إلى مكوّن النص إطلاقاً، فكل أزرار القوائم المبنية بها ظهرت فارغة منذ المرحلة 4 (START RACE / HOW TO PLAY / QUIT / RESUME / RESTART RACE / MAIN MENU / CLOSE وأيقونة الإيقاف القديمة "II")
- لهذا كانت أزرار القيادة وحدها تحمل نصوصاً (BRK والأسهم): لأن `CarController.ConfigureButton` يضبط النص بنفسه
- الإصلاح: سطر واحد `text.text = label;` داخل MakeButton — كل أزرار القوائم الثلاثة (الرئيسية + الإيقاف + النتائج) حصلت على تسمياتها فوراً
- **تباعد القائمة**: السطر الفرعي THIRD-PERSON 2D RACING كان يختفي خلف حروف العنوان الكبير — نُقل لأسفل مع الإحصاءات (BEST LAP / TOTAL LAPS) ليصبح تدرجاً نظيفاً: عنوان ← سطر فرعي ← إحصاءات ← أزرار
