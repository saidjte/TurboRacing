# TurboRacing

لعبة سباق سيارات 2D بمنظور شخص ثالث لأندرويد — مبنية بـ Unity وتُبنى تلقائياً إلى APK عبر GitHub Actions.

## كيف يعمل البناء التلقائي؟
1. عند كل `push` إلى `main` يعمل workflow ‏`.github/workflows/build-android.yml`
2. يستخدم `game-ci/unity-builder@v4` بإصدار Unity **6000.0.84f1** (منصّة Android)
3. ينفذ `BuildCommand.PerformBuild` الذي:
   - يضبط إعدادات اللاعب لأندرويد (أفقي، ARM64+ARMv7، API 24+)
   - ينشئ المشهد برمجياً (كاميرا + GameBootstrap)
   - يبني `build/Android/TurboRacing_v{الإصدار}.apk` (الاسم من GameVersion)
4. يُرفع الـ APK كـ **Artifact** باسم `TurboRacing-APK`

```
│   └── GameBootstrap.cs      يبني محتوى المشهد بالكود عند التشغيل
├── Editor/

```

## الحلبة (المرحلة 2 + v1.2.0)
- حلبة مستطيلة مغلقة **72×44 بلاطة** (بلاطة = 2×2 متر → 144×88 متراً، مساحة أكبر بـ ~2.5×) مع جزيرة عشبية داخلية
- **عرض الطريق 6 بلاطات (12 متراً)** — أعرض بـ 50% من السابق، مناورة مريحة حتى عند الأخطاء
- مشدّدان (شكانات) يضيّقان الطريق عند جزأين من المستقيمين — بفراغات مريحة (8 و 10 أمتار)
- كيرب أحمر/أبيض مرفوع على حواف الطريق + خط بداية مقلّم + بوابة انطلاق تعبر السيارة تحتها
- حواجز خرسانية مجسّمة بظلال حقيقية + أشجار ومدرّجات جمهور ولوحات إعلانات أعيد تموضعها للحلبة الجديدة
- الخروج للعشب: السرعة تنخفض إلى 45% والتماسك إلى 60% والسيارة تتعكر حتى العودة للمسار
- السباق مع عقارب الساعة — الانطلاق شرقاً من خط البداية

## نظام اللفات (المرحلة 3)
- السباق = 3 لفات: 3 نقاط تفتيش إلزامية (يمين، أعلى، يسار) ثم خط النهاية = لفة صحيحة
- نطاق كل بوابة مقيّد بعرض الطريق: قطع الطريق عبر العشب لا يحتسب
- المؤقت يبدأ فعلياً عند أول عبور لخط النهاية باتجاه السباق
- HUD: عدد اللفة من الإجمالي + زمن اللفة الحالية + أفضل لفة + آخر لفة + شارة الإصدار
- أفضل زمن وإجمالي اللفات محفوظان في PlayerPrefs (يبقيان بين الجلسات)

## الواجهات الكاملة (المرحلة 4)
- **آلة حالات مركزية** `RaceFlow`: القائمة ← عد تنازلي ← سباق ← (وقفة) ← نتائج
- **القائمة الرئيسية**: العنوان + أفضل لفة وإجمالي اللفات المحفوظين + START RACE + HOW TO PLAY (شرح كامل) + QUIT
- **عد تنازلي** 3-2-1-GO والسيارة مجمّدة فيزيائياً حتى الانطلاق
- **زر إيقاف مؤقت** II في الـ HUD (أو ESC/زر الرجوع): استئناف / إعادة السباق / القائمة — الزمن والفيزياء يتجمدان كلياً
- **شاشة النتائج** بعد 3 لفات: أزمنة اللفات كلها (الأفضل بلون مميز) + الزمن الإجمالي + تنبيه NEW RECORD! + إعادة/قائمة
- **كاميرا القائمة**: تأطير الحلبة كاملة في القائمة الرئيسية ثم انتقال فوري لكاميرا السباق

## الكاميرا (v0.5.0)
- **منظور الشخص الثالث أثناء السباق**: كاميرا مطاردة منظورية (Perspective) خلف السيارة بميلان 55°
- الدوران مقفول على اتجاه السيارة: السيارة تسير دائماً نحو أعلى الشاشة والطريق الأمامي يظهر بعمق متناقص (تأثير شبه ثلاثي الأبعاد)
- نقطة نظرة أمام السيارة لرؤية الطريق القادم + تنعيم مزدوج (الموضع والدوران منفصلان)
- **القائمة الرئيسية تبقى علوية**: تأطير الحلبة كاملة قبل الانطلاق ثم انتقال فوري لكاميرا المطاردة

## التحكم (v0.6.0 + v1.2.0)
- **قيادة يدوية كاملة (v1.2.0)**: زر بنزين GAS أخضر كبير أسفل اليمين — السيارة لم تعد تتحرك من تلقاء نفسها؛ الضغط عليه = تسارع، وإفلاته = تدحرج طبيعي يبطئها بلطف حتى التوقف (أسلوب Prometeo الأصلي DecelerateCar)، والفرامل الحمراء على يسارها (فرملة قوية، والاستمرار يرجع للخلف)
- **تخطيط قياسي**: زرا التوجيه مجمّعان أسفل اليسار + GAS والفرامل أسفل اليمين — إبهام يوجه وإبهام يقود، ومنتصف الشاشة صافٍ حيث تظهر السيارة
- **أيقونات مرسومة لكل أزرار القيادة** (أسهم + مثلث بنزين + مربع فرامل): مولّدة برمجياً — مستقلة كلياً عن الخطوط فتظهر دائماً على كل الأجهزة
- **حصانة ضد الالتصاق**: تحرير الزر تلقائياً عند انزلاق الإصبع خارجه + تتبع معرفات الأصابع (v0.6.8) — ودعم لمس متعدد كامل
- **تغذية بصرية فورية**: التوجيه يتوهج عنبرياً، البنزين أخضر ساطع، الفرامل أحمر ساطع أثناء الضغط
- **تصفير ذكي للمدخلات** عند بدء/إعادة السباق أو العودة للقائمة (لا مدخلات عالقة من جلسة سابقة)
- الفرامل توقف السيارة ثم ترجعها للخلف ببطء عند الاستمرار (أسلوب الموبايل)
- إعدادات الأزرار (حجم/شفافية/تبديل الجانبين لليساريين) تشمل زر البنزين الجديد

## المظهر شبه ثلاثي الأبعاد (v0.9.0)
- **الهدف**: جعل اللعبة تبدو ثلاثية الأبعاد دون الخروج من Unity 2D — كل ما يلي رسم إجرائي يُخلَق عند الإقلاع (بلا أي ملف صور)
- **إشارات العمق المطبقة**: ظل أرضي ناعم تحت السيارة (أقوى إشارة ارتفاع في المنظور العلوي) + ظلال متدرجة باتجاه ثابت للشمس (جنوب-شرق) تحت الجدران والأشجار واللافتة + تظليل حجم مدمج داخل سبرايتات السيارة والجدران (قبة مضيئة/حواف داكنة/Bevel) + عناصر "طويلة" ترسم فوق السيارة عند المرور قربها (أشجار + لافتة البوابة) + فينييت عدسة على الأطراف
- **السيارة (CarSkin v0.9.0)**: نفس الهندسة والفيزياء حرفياً — الطلاء الجديد: قبة مضيئة وسطاً تنسدل نحو حواف داكنة، لمعان عمود فقري، شريطا سباق مزدوجان، زجاج بثلاث لوحات وإطار أعمدة وانعكاسات مائلة، جناح خلفي بظل متدرج على الصندوق يوحي بأنه يطفو فوقه، عجلات بجنوط معدنية بلمعة علوية وصرة، مصابيح عدسات بحلقة كروم، فتحات تهوية، مرايا، شفة أمامية وعوادم، وخط ظل محيط بكامل الصورة الظلية
- **الحلبة (TrackBuilder v0.9.0)**: كل البلاطات أصبحت 128×128 بفلتر Bilinear — الجدران وجوه إسمنتية بحواف مشطوفة (أعلى/يسار مضيء، أسفل/يمين داكن) وفواصل صناديق مكدسة؛ طبقة ظلال جديدة (order 2) ترسم تدرجاً أسفل كل جدار من الجنوب وشرقه ويتضاعف عند الزوايا؛ العشب بخطوط جز مائلة 45° مستمرة عبر الخريطة كاملة (فترة تقسم 128) وزهور نادرة؛ الإسفلت ببقع قيمة كبيرة وشقوق وحصى؛ الكيرب بشرائح متدرجة الإضاءة وخط خارجي داكن وظل اتصال نحو الإسفلت؛ عشرة أشجار كبيرة بالجزيرة وأربعون على الهوامش بتاج طبقي وتنويع لوني وظل أرضي؛ بوابة البداية: قاعدتا أعمدة + لافتة شطرنج تعلو السيارة (order 12) بظل على الطريق؛ حلقة طلاء بيضاء متآكلة وسط الجزيرة
- **الفيكييت (GameBootstrap)**: كانفاس ترتيب -10 (فوق العالم وتحت كل الواجهات والأزرار) بتدرج شعاعي يصل 34% عند الزوايا — لا يعيق اللمس (raycastTarget=false)

## تطوير السيارة والإعدادات المتقدمة (v0.8.0)
- **سيارة مرسومة إجرائياً**: مولّد `CarSkin` يبني سبرايتين برمجياً (128×256 بكسل بنفس أبعاد الفيزياء القديمة تماماً) — هيكل سيارة سباق بأنف مدبب ومؤخرة عريضة وزوايا مستديرة، فوقه طبقة تفاصيل ثابتة الألوان: أربع عجلات بمراكز فولاذية، قمرة زجاجية (زجاج أمامي وسقف وزجاج خلفي)، جناح خلفي، مصابيح أمامية وخلفية — بلا أي أصول خارجية
- **ثمانية ألوان طلاء**: الهيكل أبيض يُلوَّن عبر `SpriteRenderer.color` (التفاصيل لا تتأثر) — الأحمر افتراضياً، والتلطيخ على العشب يتراكب فوق أي لون بشكل صحيح
- **ثلاثة مستويات ضبط أداء**: STOCK (14 م/ث، متوازن) / SPORT (15.5 م/ث، ألزق وأسرع) / TURBO (17 م/ث، الأسرع مع انزلاق أكثر) — تضبط السرعة القصوى والتسارع وسرعة الدوران والتماسك دفعة واحدة، مع عرض حي للأرقام في صفحة الإعدادات
- **حساسية توجيه قابلة للضبط**: مضاعف 0.7x–1.4x على سرعة الدوران فقط (بقية الفيزياء سليمة)، وعقاب العشب أصبح يُركَّب فوق تماسك المستوى المختار عبر `SetGripOverride` بدل الكتابة المباشرة
- **صفحة إعدادات بتبويبات** (كانفاس ترتيب 50 فوق كل القوائم، تُفتح من القائمة الرئيسية ومن الإيقاف المؤقت): SOUND (مستوى عام/محرك/مؤثرات + زر تجربة) / CONTROLS (حجم الأزرار، شفافيتها، حساسية التوجيه، تبديل الجانبين لليساريين) / CAR (طلاء + ضبط) / CAMERA (مسافة الكاميرا 0.8x–1.3x + تعطيل اهتزاز التصادم)

## الصوت والمؤثرات (v0.7.0 — المرحلة 5)

## إصلاح دوران السيارة الذاتي والتحكم (v0.6.8)
- **السبب الجذري لدوران السيارة من تلقاء نفسها**: `angularDamping = 0` مع توجيه عبر `MoveRotation` — دالة التوجيه تخرج مبكراً عندما لا يضغط اللاعب، فلا شيء يمس السرعة الزاوية التي ضخّها تصادم الجدار، ومع إخماد الدوران = صفر تبقى السيارة تدور إلى الأبد وكاميرا المطاردة تدور معها
- **الإصلاح الجذري**: التوجيه أصبح يضبط `rb.angularVelocity` صريحاً كل خطوة فيزيائية — بدون مدخل توجيه تكون السرعة الزاوية صفراً (أي دوران من تصادم يموت فوراً)، ومع التوجيه يطابق الدوران مدخل اللاعب حصراً
- **تحصين المدخلات (تتبع الأصابع)**: لكل زر مجموعة معرفات المؤشرات الضاغطة عليه؛ الانزلاق من زر توجيه إلى الآخر يفعّل الزر الثاني فوراً (PointerEnter)، والضغط بجانب الزر ثم الانزلاق عليه يعمل أيضاً، وكل إطار تُمسح المعرفات التي انتهى لمسها فلا يبقى أي زر عالقاً مهما كانت طريقة رفع الإصبع
- **مادة الهيكل**: احتكاك = 0 مع ارتداد خفيف 0.15 — ملامسة الجدار تصبح انزلاقاً ناعماً بدل الالتصاق والتباطؤ المفاجئ
- **ثبات المستقيمات**: التوجيه يخف 25% تدريجياً قرب السرعة القصوى (قابل للضبط عبر highSpeedTurnFactor)
- إضافة: تصفير السرعة الزاوية عند إعادة السباق حتى لا تستأنف السيارة دوراناً قديماً
